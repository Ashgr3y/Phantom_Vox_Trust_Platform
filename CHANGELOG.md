# Changelog

## 1.0.0 - 2026-09-22

- Replaced the single-page classifier demo with an eight-workspace operations platform.
- Corrected all executable-model references from AASIST to RawNetLite.
- Added authenticated, tenant-scoped FastAPI REST and WebSocket APIs.
- Added SQLite persistence and PostgreSQL-compatible configuration.
- Added recency-weighted TrustFusion policy logic with quality abstention and hysteresis.
- Added a stored transaction hold, verification, incident, and supervisor-escalation workflow.
- Added hash-chained audit events and integrity verification.
- Disabled raw-audio retention by default and removed bundled captured call chunks.
- Preserved the RawNetLite model files behind a lazy-loading adapter.
- Added policies, trusted voices, integrations, model trust, privacy, and investigation workspaces.
- Added four reproducible judge scenarios and fictional Indian-context seed data.
- Added evaluation tooling without fabricated metrics.
- Added Docker, Windows, Ubuntu, API, security, threat-model, and judge documentation.
- Added backend, frontend, privacy, and build tests.
